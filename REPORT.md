# Отчет по лабораторной работе №3: Линейные модели

## Данные и подготовка
В работе использовано два датасета. Первый, `Student_Performance.csv`, применялся для регрессии. Целевую переменную `Performance Index` оставили как есть, а текстовый признак `Extracurricular Activities` перевели в числа (Yes=1, No=0). 
Второй датасет, `german.csv`, применялся для классификации. Тут целевая переменная находится в первом столбце (`Creditability`).
Перед подачей в модели все признаки масштабировались через `StandardScaler`. Без этого градиентный спуск работает плохо и медленно. Данные поделили на train и test (80 на 20) с `random_state=42`.

## Гипотезы и эксперименты
Своя линейная регрессия и логистическая регрессия реализованы вручную с помощью пакетного градиентного спуска. 
Для регрессии заданы параметры learning_rate=0.05 и 800 эпох. Для логистической регрессии взяты learning_rate=0.1 и 1000 эпох, функция потерь - бинарная кросс-энтропия.
Затем своя логистическая регрессия сравнивалась с готовыми моделями из sklearn: `DecisionTreeClassifier` и `KNeighborsClassifier`. Обучение проводилось на тех же самых данных.

## Метрики
После запуска тестов на тестовой выборке получены такие значения:
- Линейная регрессия: итоговый MSE (Loss) = 4.1697.
- Логистическая регрессия (своя): F1-score = 0.8339.
- Decision Tree: F1-score = 0.7939.
- KNN: F1-score = 0.8125.

## Выводы
Своя реализация логистической регрессии неожиданно обошла готовые алгоритмы из sklearn. F1-мера у нее самая высокая (0.8339). Скорее всего, данные в german.csv достаточно хорошо разделяются линейно, поэтому сложные модели не дают прироста.
Дерево решений показало худший результат (0.7939), возможно, оно переобучилось на обучающей выборке. KNN заняло среднее место (0.8125). Главный вывод: ручной градиентный спуск отлично работает и выдает адекватные результаты, если правильно отмасштабировать признаки.

## Воспроизводимость
Все тесты запускались с фиксированным `random_state=42`. Параметры обучения (learning rate и количество эпох) указаны выше. Код для проверки всех функций лежит в файле `test_my_code.py`.
